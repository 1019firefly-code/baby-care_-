# baby-monitor

  AI 婴儿监护系统。和普通摄像头 App 的本质区别：不用盯着屏幕，有事它主动找你。

  核心判断只有一条：**"哭"不是异常，"哭了没人管"才是异常。** 只有当宝宝持续哭满
  3 分钟、且画面里全程没有成人出现时，系统才会通过企业微信把告警和现场抓拍推到
  家长手机上。其余时间保持沉默。

  ## 当前状态

  早期开发中，整体规划六个阶段，目前在阶段 2。

  - 阶段 1（哭声检测 + 微信推送 +
  心跳）：原型已完成并通过测试，正在按新的工程规范迁入本仓库
  - 阶段 2（摄像头接入，RTSP）：进行中。已实测取流连通，2880×1620 @ 15fps
  - 阶段 3 至 6（婴儿姿态检测、AI 二次复核、实地调参、床面异物检测）：未开始

  ## 快速开始

  ```bash
  # 1. 下载代码
  git clone https://github.com/WyzonXie/baby-monitor.git
  cd baby-monitor

  # 2. 创建并激活虚拟环境（Windows）
  py -m venv .venv
  .venv\Scripts\activate

  # 3. 安装依赖
  pip install -r requirements.txt
  ```

  第 4 步，创建你自己的 `config.py`。仓库里没有这个文件——它存放摄像头密码等
  敏感信息，被 `.gitignore` 排除在版本控制之外，每个使用者需要自建：

  ```python
  # config.py
  RTSP_URL = "rtsp://用户名:密码@摄像头IP/stream1"
  ```

  第 5 步，验证摄像头连通：

  ```bash
  python check_camera.py
  ```

  成功时会打印摄像头的实际分辨率与帧率。

  ## 技术选型

  本地筛查加 Claude API 复核的两层级联架构，推送走企业微信机器人（纯出站，
  家庭网络零暴露面）。完整选型与取舍理由见 [tech.md](./tech.md)。

  ## 隐私与数据

  - 不做连续录像，只保存触发告警瞬间的单帧画面
  - 会离开家庭网络的数据仅两类：告警抓拍（经企业微信）、可疑时刻画面（送 Claude API
  复核）

  ## 已知限制

  - 微信推送穿不透手机的勿扰和静音模式。主场景为白天，此限制已接受
  - 房间内白噪音机可能压低哭声识别分数，阈值需要实地调参（阶段 5）
  - 本项目使用的部分婴儿专用视觉模型为非商用许可，本项目仅限个人自用。
    任何商业化使用前，整条视觉链必须替换重做
